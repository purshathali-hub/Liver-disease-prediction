# 🩺 AI Liver Disease Prediction

An AI-powered web application that predicts the likelihood of liver disease using machine learning. The application provides a simple and intuitive interface for entering patient details and receiving prediction results instantly.

---

## 📌 Features

- Predicts liver disease risk using a trained Machine Learning model
- Simple and user-friendly interface
- Fast predictions
- Responsive design
- Built with React and TypeScript

---

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Machine Learning
- Python
- Jupyter Notebook
- Scikit-learn
- Pandas
- NumPy

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/roshaninishad25/Liver-disease-prediction.git
```

Move into the project directory

```bash
cd Liver-disease-prediction
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```
